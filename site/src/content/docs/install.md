node-bonsai runs in a terminal, the text window on your computer. You copy the
project from GitHub, then run a few commands.

## What you need

- **Node.js 22 or newer.** Node.js runs the project. Download it from
  [nodejs.org](https://nodejs.org/).
- **Git.** Git copies the project from GitHub.
- **A terminal.** Open the terminal app on your computer.

## Install steps

Run these commands in order:

```bash
git clone https://github.com/areimel/node-bonsai.git
cd node-bonsai
npm install
```

- `git clone` copies the project into a new folder called `node-bonsai`.
- `cd node-bonsai` moves the terminal into that folder.
- `npm install` downloads the parts the project needs.

Stay in the `node-bonsai` folder for the commands on the Quick start page.
There you draw your first tree.
